# Technology Stack

## Runtime

No build runtime is required. Open `index.html` directly in a modern browser or serve the directory with any static HTTP server.

## Frontend

- HTML5 for semantic document structure
- CSS3 for layout, responsive behavior, animation, and visual styling
- No JavaScript framework or external UI library

## Styling Approach

- CSS custom properties for the design tokens
- CSS Grid and Flexbox for responsive layout
- Media queries for mobile, tablet, and desktop adaptation
- `prefers-reduced-motion` support for motion accessibility

## Dependencies

None. The landing page must remain self-contained and portable.
