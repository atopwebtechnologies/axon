# Flowly Task Management Landing Page

## Product Summary

Flowly is a task-management software concept that helps individuals and teams organize work, prioritize what matters, and make steady progress without unnecessary complexity. This project delivers a responsive marketing landing page that communicates that value clearly.

## Purpose

Create a polished, conversion-focused landing page using only semantic HTML and CSS. The page should establish the product promise, explain its core benefits, and make plan selection easy.

## Audience

- Individuals looking for a calmer way to organize tasks
- Small teams coordinating projects and day-to-day work
- Prospective customers comparing task-management tools

## Core Experience

Visitors should immediately understand that Flowly makes work feel clearer and more manageable, then be able to:

1. Start a free trial from the hero call to action.
2. Scan three core product benefits.
3. Compare Personal, Team, and Business plans.

## Scope

- Responsive desktop, tablet, and mobile layouts
- Hero banner with product identity, headline, supporting copy, and CTA
- Three-column feature section
- Accessible pricing comparison table
- Pure HTML and CSS; no frameworks, JavaScript, or external runtime dependencies

## Success Criteria

The page is visually cohesive, readable at common viewport sizes, semantically structured, and makes the primary action and pricing choices easy to understand.
