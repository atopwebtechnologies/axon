# Technology Stack: Scandinavian Developer Portfolio Landing Page

## Frontend Core
- **Language**: HTML5, Modern ECMAScript (JS ES6+)
- **Styling**: Vanilla CSS3 (Custom CSS Custom Properties / Variables, Flexbox, Grid, CSS Transitions/Keyframes)
- **Framework**: Native Vanilla Web Application (Zero heavy framework overhead, maximum performance and design control)

## Tooling & Build System
- **Build Tool**: Vite (Lightning fast dev server & production bundler)
- **Package Manager**: npm

## Architecture & Hosting
- **Architecture**: Static Web Application (Single Page Landing Page)
- **Backend**: None (Pure client-side logic with client-side form validation)
- **Deployment Target**: Static Web Hosting (Vercel / GitHub Pages / Netlify / Firebase Hosting)
