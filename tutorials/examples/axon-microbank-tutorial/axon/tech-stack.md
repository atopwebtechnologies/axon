# Technology Stack — Axon MicroBank Tutorial

## Scope

This project is currently focused on the **frontend** only. Backend and database integration are deferred to future phases.

## Frontend

| Layer | Technology | Notes |
|---|---|---|
| Framework | **React** | Component-based UI library; industry-standard for web tutorials |
| Language | **JavaScript / TypeScript** | TypeScript recommended for type safety and better DX |
| Build Tool | **Vite** | Fast dev server and build tool; modern replacement for CRA |
| Styling | **CSS Modules / Vanilla CSS** | No heavy CSS framework; keeps focus on React concepts |
| Routing | **React Router** | Standard client-side routing for SPAs |
| State Management | **React Context / useState** | Sufficient for MVP scope; avoids over-engineering |
| HTTP Client | **Fetch API / Axios** | For eventual API integration |
