# Product Guidelines: Scandinavian Design System & Brand Identity

## Design & Aesthetics
- **Style**: Scandinavian Minimalist — clean lines, balanced proportions, generous negative space, warm organic feels, and functional clarity.
- **Color Palette**:
  - Background (Cream Base): `#FFFAF3`
  - Container / Card Warm Accent: `#FFF2DB`
  - Highlight / Soft Accent: `#FFE5BF`
  - Accent / Primary Action Crimson: `#F62440`
  - Text Primary: `#1E1E1E`
  - Text Secondary: `#5A5A5A`
- **Typography**: Clean sans-serif pairings (Inter / Outfit / Plus Jakarta Sans), crisp hierarchy, generous line heights (`1.6`), uppercase tracked section labels (`letter-spacing: 0.12em`).
- **Motion & Interactions**: Subtle CSS transitions (200-300ms ease), gentle hover elevations, smooth anchor scrolling, crisp button micro-feedbacks.

## Tone & Voice
- **Tone**: Professional, confident, elegant, understated, and transparent.
- **Content Style**: Concise headlines, active verbs, data-driven achievement summaries, zero fluff or excessive jargon.

## UX Principles
- **Accessibility**: High color contrast (WCAG AAA for text), clear focus indicators, full keyboard navigation, ARIA semantics.
- **Responsiveness**: Mobile-first responsive layouts adjusting gracefully across mobile, tablet, and desktop viewports.
- **No Backend**: Self-contained client-side architecture with zero external runtime dependencies.
